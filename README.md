# pi-subagents

Subagents for [Pi](https://pi.dev). Each one runs in its own Pi process with your extensions
loaded, and you can watch and steer it while it works.

Work in progress.

## Install

```bash
pi install git:github.com/kacperkwapisz/pi-subagents
```

Requires Pi 1.x.

## Development

```bash
npm install
npm run check
npm test
```
